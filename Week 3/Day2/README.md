# Day 2 - TaskFlow

TaskFlow is a React task-management dashboard built with React 19 and Vite.
It lets you organize tasks and track their status and priority.

## Features

- Add, edit, and delete tasks
- Search tasks by title
- Filter tasks by status and priority
- View task statistics on the dashboard
- Save tasks in the browser with `localStorage`

## Run locally

Open a terminal in the `taskflow` folder and run:

```bash
npm install
npm run dev
```

Vite prints the local URL after the development server starts.

## Other commands

```bash
npm run build
npm run lint
npm run preview
```

The application source is in [`taskflow/src`](./taskflow/src), and the Vite
project configuration and npm scripts are in [`taskflow/package.json`](./taskflow/package.json).
