## How to Run

Open a terminal in the `Day1` folder:

```bash
cd "week 4/Day1"
tsc typescript-practice.ts
node typescript-practice.js
```

1. `tsc` checks the types and creates `typescript-practice.js`.
2. `node` runs the generated JavaScript file.
3. The output is printed in the **terminal**, not in the browser console.

To compile with strict type checking:

```bash
tsc typescript-practice.ts --strict
```

## Quick Notes by Topic

### 1â€“3. What TypeScript is and why it is used

```
app.ts  â†’  TypeScript compiler (tsc)  â†’  app.js  â†’  Browser / Node
```

Browsers do not understand TypeScript. Types exist only during development and are removed in the final JavaScript.

### 4. Type annotations

```ts
let price: number = 2500;

function calculateTotal(price: number, quantity: number): number {
  return price * quantity;
}
```

### 5. Primitive types

```ts
const storeName: string = "TechMart";
const taxRate: number = 17;
const isStoreOpen: boolean = true;
const closingNote: null = null;
const couponCode: undefined = undefined;
```

`null` means "intentionally empty". `undefined` means "no value was set".

### 6. Arrays

```ts
const prices: number[] = [4500, 1500, 3200];
const names: string[] = [];
```

Always annotate empty arrays.

### 7. Objects

```ts
const customer: {
  name: string;
  address: { street: string; country: string };
} = { /* ... */ };
```

### 8. Functions

```ts
function addTax(price: number, rate: number = 17): number { /* ... */ }
function logMessage(message: string): void { /* ... */ }
function applyToPrices(prices: number[], callback: (price: number) => string): string[] { /* ... */ }
```

### 9. Optional properties

```ts
function showContact(user: { name: string; phone?: string }): string {
  return user.name + ": " + (user.phone ?? "Phone not provided");
}
```

Optional parameters must come after required parameters.

### 10. Union types

```ts
type Status = "pending" | "shipped" | "delivered";

function formatId(id: string | number): string {
  if (typeof id === "string") return id.toUpperCase();
  return "ID-" + id.toFixed(0);
}
```

### 11. Type aliases

```ts
type ID = string | number;
type OrderStatus = "pending" | "shipped" | "delivered";
```

### 12. Interfaces

```ts
interface User {
  id: number;
  name: string;
  email: string;
  phone?: string;
}

interface Admin extends User {
  role: "admin" | "superadmin";
}
```

**Rule I follow:** `interface` for object shapes, `type` for unions and literal types.

### 13. Type inference

```ts
let city = "Lahore";      // inferred as string
const scores = [90, 85];  // inferred as number[]
```

Always annotate function parameters and empty arrays. Let inference handle the rest.

## Common Mistakes and Fixes

| Mistake | Fix |
|---------|-----|
| Using `String`, `Number`, `Boolean` (capital letters) | Use lowercase: `string`, `number`, `boolean` |
| Missing parameter types: `function add(a, b)` | Annotate: `function add(a: number, b: number)` |
| Using `any` to silence errors | Avoid `any`; use a proper type or a union |
| Using an optional value without checking | Use `if`, `?.` or `??` |
| `if (discount)` when `0` is a valid value | Use `discount !== undefined` |
| Calling a string method on `string \| number` | Narrow first with `typeof` |
| `type Product { ... }` (missing `=`) | `type Product = { ... }` |
| `interface User = { ... }` (extra `=`) | `interface User { ... }` |
| Required parameter after an optional one | Put required parameters first |
| Running `node file.ts` | Run `node file.js` after compiling |

## Troubleshooting

**`tsc` is not recognized**
Install TypeScript with `npm install -g typescript`, then close and reopen VS Code. Alternative without installing:

```bash
npx -p typescript tsc typescript-practice.ts
```

**PowerShell says scripts are disabled**

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

**The generated `.js` file is empty (only `"use strict"`)**
The `.ts` file was empty or not saved. Press `Ctrl + S` and compile again.

**`Cannot redeclare block-scoped variable`**
Two `.ts` files in the same folder use the same variable names. Keep `export {};` at the top of each file.
