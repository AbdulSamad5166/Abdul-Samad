# Day 4 - Responsive Web Design

This project focuses on converting the Day 3 desktop portfolio webpage into a fully responsive website.

## Topics covered

- Responsive design
- Mobile-first development
- Media queries
- Breakpoints
- Responsive typography
- Responsive images
- Mobile navigation
- Responsive cards and grids
- Desktop/tablet/mobile layouts
- Basic accessibility
- Browser Developer Tools
- CSS debugging

## Hands-on task

"Convert the Day3 desktop portfolio webpage into a fully responsive website."

Day 4 keeps the existing portfolio content, structure, and visual identity from the Day 3 project, while improving the layout for smaller screens through responsive CSS techniques.

The design preserves the original Day 3 Flexbox, Grid, and positioning concepts, while adding mobile-first adjustments, media queries, and responsive behavior across desktop, tablet, and mobile devices.
