## 🎯 Day 2 CSS Concepts Demonstrated

| # | Concept | Implementation in Project |
|---|---|---|
| 1 | **What is CSS** | Explained in header comments of `style.css` (Cascading Style Sheets separating styling from HTML). |
| 2 | **Inline, Internal & External CSS** | Primary styling implemented via external `style.css` (`<link rel="stylesheet">`); educational demonstrations of internal `<style>` and inline `style=""` included in `index.html`. |
| 3 | **CSS Selectors** | Element selectors (`body`, `header`, `p`), class selectors (`.section-card`, `.skill-badge`), ID selectors (`#home`, `#about`), and grouped selectors (`th, td`). |
| 4 | **Classes and IDs** | Applied semantically throughout the HTML structure for clean targeting. |
| 5 | **Colors** | Hexadecimal colors (`#1a365d`, `#2b6cb0`), RGB values, and named colors (`white`). |
| 6 | **Fonts & Typography** | `font-family: 'Segoe UI', Arial, sans-serif`, `font-size`, `font-weight: 600/700`, `line-height: 1.6`. |
| 7 | **Text Styling** | `text-align: center`, `text-decoration: none`, `letter-spacing: 1px`. |
| 8 | **Backgrounds** | `background-color` applied across page body, header, navigation, cards, badges, and footer. |
| 9 | **Borders** | `border`, `border-bottom`, `border-collapse` on table, and border removals (`border: none`). |
| 10 | **Border Radius** | Rounded cards (`border-radius: 8px`), pill-shaped skill badges (`20px`), circular avatar (`50%`). |
| 11 | **Box Model** | Explicit control over Content, Padding, Border, and Margin with `box-sizing: border-box`. |
| 12 | **Margin & Padding** | Centering containers with `margin: 30px auto;`, spacing form groups, and internal element padding. |
| 13 | **Width and Height** | Container restrictions (`max-width: 850px; width: 90%`), image dimensions (`180px`), textarea height (`120px`). |
| 14 | **CSS Units** | Pixels (`px`) for fixed dimensions/fonts and percentages (`%`) for responsive widths. |
| 15 | **Display Property** | `display: block` (headings, inputs, profile photo), `display: inline-block` (navigation links, skill badges, buttons). |
