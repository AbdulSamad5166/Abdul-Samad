# Week 1 - Final Project

## Project Overview

This is the completed Week 1 frontend portfolio project. It brings together the core lessons from the internship into a professional, modern personal portfolio website while preserving the original learning structure and content.

## Technologies

- HTML5
- CSS3

## HTML5 and Semantic HTML

The project uses proper HTML5 structure with semantic elements such as:

- header
- nav
- main
- section
- article
- footer

This preserves accessibility and improves readability for both users and browsers.

## CSS3 and Week 1 Concepts

The website demonstrates the core concepts covered in Week 1, including:

- CSS selectors
- Box model
- Flexbox
- CSS Grid
- Responsive design
- Media queries
- Basic accessibility
- CSS animations and transitions

## Responsive Design

The portfolio is designed to be usable across common screen sizes, including:

- Desktop
- Tablet
- Mobile

The layout adapts to different viewport widths using media queries and flexible layout techniques. The design avoids unnecessary horizontal overflow and keeps content readable on smaller devices.

## Accessibility

Accessibility basics were considered throughout the build, including:

- Semantic heading structure
- Meaningful alt text for images
- Labelled form inputs
- Readable contrast
- Focus states for interactive elements
- Keyboard-friendly navigation

## CSS Animations and Transitions

A subtle and professional visual layer was added through CSS animations and transitions, including:

- Page load animation
- Header and navigation entrance effects
- Hero content motion
- Button hover effects
- Card lift animations
- Image hover motion
- Smooth section transitions
- Footer reveal animation

## Responsive Testing

The website was reviewed and adjusted for responsive behavior at:

- Desktop: 1440px
- Desktop/Laptop: 1024px
- Tablet: 768px
- Mobile: 480px
- Small mobile: 375px
