# Week 2 Day 3

Beginner JavaScript practice using student records and modern array and object features:

- Destructuring object properties
- Creating name lists with `map`
- Filtering passing students with `filter`
- Finding a student with `find`
- Checking all students with `every`
- Calculating fees with `reduce` and rest parameters
- Inspecting objects with `Object.keys`, `Object.values`, and `Object.entries`
- Using optional chaining and nullish coalescing
- Copying and updating objects with spread syntax

## Run

Run the exercises with Node.js:

```bash
node javascript.js
```
